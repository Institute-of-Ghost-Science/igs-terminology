# Agent Notes

- Treat terminology expansion as an approval-first editorial workflow.
- When the user asks to add, define, draft, or consider terms, propose candidates or draft a single term for review before editing `terms.json`, `terms.csv`, version archives, release metadata, or website terminology data.
- Do not save terminology changes to disk unless the user explicitly says to save or add the approved term.
- When changing a term's public data, including tags, aliases, related terms, references, or definition text, update that term's `versionUpdated` to the current release version.
- Do not commit, push, deploy, or sync terminology unless the user explicitly asks for that action.
- Follow `EDITORIAL_GUIDE.md` for terminology voice, definitions, related terms, tags, and approval workflow.
